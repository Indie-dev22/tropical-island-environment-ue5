# 🌴 Tropical Island Environment — Unreal Engine 5

This project showcases a fully hand-crafted **tropical island environment** built in **Unreal Engine 5**, designed for cinematic rendering, environment art practice, and real-time worldbuilding.  
The scene includes realistic water shading, foliage placement, natural lighting, and high-quality EXR export workflows for maximum visual fidelity.

---

## 🚀 Features

### 🌊 **Environment Highlights**
- Realistic tropical water shader (clarity, depth, refraction)
- Palm trees, dense foliage, rocks, and natural beach layout
- Cliff formation with arch structure
- Abandoned boat & environmental storytelling elements
- Optimized landscape material

### 🎥 **Cinematic Elements**
- Multiple cinematic camera shots
- Smooth flyovers and dynamic sequences
- Rendered using EXR image sequence
- Final editing & color grading done in Blender

### 🔥 **Technical Workflow**
- Engine: **Unreal Engine 5**
- Lighting: **Lumen + Skylight**
- Rendering: **EXR Sequence (4K Ready)**
- Editing: **Blender Video Sequencer**
- Color Management: Filmic grading, vignette, multi-layer correction
